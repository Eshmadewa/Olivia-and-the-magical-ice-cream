# Оливия и волшебное мороженое

Небольшой законченный браузерный платформер для детей. Оливия постоянно едет на одном серо-коричневом пушистом коте. Референс пользователя пока не приложен: оригинальный персонаж по текстовому описанию, без заявления о портретном сходстве.

## Принятые решения
- Чистые HTML, CSS, Canvas 2D, Web Audio; без сборки, сторонних ресурсов, сетевых запросов и зависимостей игры.
- Пять миров: клубничная поляна, карамельный лес, зефирные облака, шоколадные пещеры, замок Короля Пломбира.
- Физика с фиксированным шагом 1/120 с, coyote time 110 мс, буфер прыжка 140 мс, регулируемая высота прыжка.
- Три сердца, контрольные точки, дружелюбные противники, секрет в каждом мире, движущиеся платформы, финальный босс.
- Автосохранение в localStorage: открытые миры, уникальные мороженые, звёзды и косметические аксессуары. Внешность героев постоянна.
- Клавиатура, сенсорные кнопки, пауза при сворачивании. Музыка синтезируется после взаимодействия.
- GitHub Pages, в том числе адрес /имя-репозитория/: только относительные пути, .nojekyll, workflow публикации.

## Структура и порядок
1. `js/core.js`, `js/levels.js`: физика и достижимые уровни; `node --test tests/*.test.cjs`.
2. `js/art.js`, `js/audio.js`, `js/game.js`: оригинальная графика, звук и игровой цикл.
3. `index.html`, `styles.css`: меню, HUD, мобильное управление, выбор мира и аксессуаров.
4. `server.cjs`, `.github/workflows/pages.yml`, `README.md`: локальный запуск и публикация.

## Проверка
- `npm test`: прыжок, coyote time, буфер, приземление, границы шага, достижимость всех обязательных разрывов, сохранения.
- `npm start`: сервер http://localhost:4173.
- Реальный Chromium: загрузка, старт, движение, прыжок, пауза, повтор, меню, мобильная вёрстка, отсутствие ошибок.
- Никаких чужих персонажей, изображений или музыки. Никаких API-ключей и сервера в публикации.

## Стиль
Обычные функции и небольшие тематические файлы, namespace `Olivia`. Пример: `const speed = approach(player.vx, targetSpeed, acceleration * dt);`. Все пользовательские строки на русском.
