# Проверка игры

Команды выполняются из корня проекта.

## Автоматические тесты без зависимостей

```sh
node --test tests/*.test.cjs
```

Физика: высота и дальность прыжка, управление высотой отпусканием кнопки, coyote time, отсутствие двойного прыжка, буферизация, защита от пролёта сквозь платформу, движение вместе с платформой. Для каждого из пяти миров тест симулирует пересечение каждого обязательного разрыва реальной функцией движения. Также проверяются повреждённые и заблокированные сохранения.

## Реальный браузер

Тестовые инструменты не нужны игрокам и не публикуются вместе с игрой.

```sh
npm install --no-save playwright
npx playwright install chromium
node server.cjs
```

В другом терминале:

```sh
node tests/browser-smoke.cjs
node tests/browser-playthrough.cjs
```

- `browser-smoke.cjs` проверяет загрузку из `/preview-repo/`, клавиши и сенсорные кнопки, паузу, перезапуск, меню, фокус после выбора мира, сохранение настройки звука, прямой запуск `file://`, экраны 1440×1100, 390×844, 844×390 и 320×720, ошибки консоли и загрузки ресурсов.
- `browser-playthrough.cjs` проходит все пять миров обычными клавишами с первого запуска до финальных ворот. Используется виртуальное время браузера; координаты персонажа не изменяются. Тест подтверждает достижение финала, босса, открытие следующих уровней, аксессуаров и сохранение коллекции. `Olivia.inspect()` предоставляет только снимок состояния для диагностики, а не команды изменения игры.
- Скриншоты находятся в `test-results/`; они исключены из Git.

Переменные окружения: `TEST_URL` — адрес игры, `BROWSER_PATH` — установленный Chrome вместо браузера Playwright, `PLAYWRIGHT_PATH` — путь к уже установленному пакету, `TEST_START_SERVER=1` — поднять тестовый сервер в том же процессе, `PORT` — порт этого сервера.

## Ручная проверка перед публикацией

1. На настоящем телефоне одновременно удерживайте движение и прыжок; проверьте поворот экрана, паузу и полноэкранную кнопку.
2. В Safari и Firefox проверьте звук после первого нажатия и сохранение после перезагрузки.
3. Пройдите верхнюю тропинку первого мира: платформа около x=875 → платформа x=1040 → секретная звезда. Найденная звезда добавляет четыре мороженых.
4. После загрузки на GitHub Pages откройте URL из Settings → Pages и проверьте, что ни один ресурс не возвращает 404.

Проверка эмуляцией мобильного экрана в Chromium не заменяет тест на физических устройствах и не является заявлением о проверке Safari/Firefox. Удалённая публикация не выполняется локальными тестами.
