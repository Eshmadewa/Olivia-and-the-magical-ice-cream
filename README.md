# Оливия и волшебное мороженое

**Olivia's Ice Cream Adventure** — небольшой оригинальный 2D-платформер. Оливия путешествует на большом полосатом коте по пяти съедобным мирам. Игра работает на компьютере и телефоне, без установки библиотек, аккаунтов или сервера приложений.

## Запуск локально

**Проще всего:** откройте `index.html` в современном браузере. Все изображения и музыка создаются локально, интернет не требуется.

**Рекомендуемый вариант для разработки:** установите Node.js и в папке игры выполните:

```sh
node server.cjs
```

Откройте **http://localhost:4173**. Эквивалентная команда при наличии npm — `npm start`. `npm install` для игры не нужен.

Адрес **http://localhost:4173/preview-repo/** имитирует публикацию в подпапке GitHub Pages. Сервер также доступен в локальной сети: для проверки на настоящем телефоне подключите его к той же Wi-Fi-сети и откройте `http://IP-ВАШЕГО-КОМПЬЮТЕРА:4173` (если брандмауэр разрешает локальные подключения). Остановить сервер — `Ctrl+C`.

## Публикация на GitHub Pages

### Вариант A: GitHub Actions (рекомендуется)

1. Создайте на GitHub новый **публичный** репозиторий, например `olivia-ice-cream`.
2. Загрузите в его корень содержимое этой папки. `index.html` должен находиться прямо в корне, а не во вложенной папке. Сохраните папки `js`, `assets`, `tests`, `.github` и файл `.nojekyll`.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Вкладка **Actions → Publish Olivia to GitHub Pages → Run workflow**. Выберите `main` или `master`. В дальнейшем публикация запускается автоматически при отправке изменений в любую из этих веток. Для репозитория используйте одну основную ветку.
5. Дождитесь зелёной отметки у обоих этапов. Адрес игры появится в **Settings → Pages** и в результате задания `deploy`:

```text
https://ВАШ-ЛОГИН.github.io/olivia-ice-cream/
```

Workflow `.github/workflows/pages.yml` проверяет синтаксис JavaScript, запускает тесты физики и публикует только `index.html`, `styles.css`, `.nojekyll`, `js/`, `assets/`. Node.js на GitHub нужен только для проверки; посетителям ничего устанавливать не нужно.

Если проект ещё не связан с удалённым репозиторием, можно использовать Git вместо загрузки через сайт (подставьте свой URL):

```sh
git add .
git commit -m "feat: add Olivia's Ice Cream Adventure"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/olivia-ice-cream.git
git push -u origin main
```

Если `origin` уже существует, повторять `git remote add` не нужно. Посмотреть адрес: `git remote -v`.

### Вариант B: публикация из ветки, без Actions

1. Загрузите игру в корень основной ветки репозитория.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main` (или `master`) и папку **/(root)**, затем **Save**.
4. Чтобы не запускать одновременно второй способ публикации, отключите workflow **Publish Olivia to GitHub Pages** во вкладке **Actions** или не добавляйте `.github/workflows/pages.yml` при этом варианте.
5. Дождитесь сообщения о публикации и откройте адрес из **Settings → Pages**.

Настройка соответствует [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) и [рекомендациям по workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

### Почему работает в подпапке

Все ресурсы подключены через `./styles.css`, `./js/...`, `./assets/...`. В игре нет абсолютных путей от корня сайта, CDN, `fetch`, роутера, backend API или шага сборки. Переименовывать репозиторий можно без изменения кода. Важны регистр имён файлов и целостность структуры папок.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | ← → или A D | Кнопки ◀ ▶ |
| Прыжок | Пробел, ↑ или W | Круглая кнопка ↑ |
| Высокий прыжок | Удерживать кнопку прыжка | Удерживать ↑ |
| Короткий прыжок | Быстро отпустить | Быстро отпустить ↑ |
| Пауза | Esc или Ⅱ | Ⅱ |
| Повтор уровня | R или кнопка в меню | Кнопка в меню паузы |
| Полный экран | ⛶ в углу | ⛶ или горизонтальное положение |

На телефоне можно одновременно удерживать движение и прыжок. Кнопки не вызывают прокрутку или масштабирование. При переключении вкладки или потере фокуса игра встаёт на паузу. Где Fullscreen API недоступен, используется развёрнутое игровое поле внутри страницы.

## Миры и правила

1. **Клубничная поляна** — первые прыжки, улитки, собачки-мороженки, клубничный джем.
2. **Карамельный лес** — сладкие пружинки и липкая карамель.
3. **Зефирные облака** — восходящие воздушные потоки, зефирные существа и леденцовые птицы.
4. **Шоколадные пещеры** — светлячки, кристаллы и лужицы горячего какао.
5. **Замок Пломбира** — финальная игра с Королём. Перепрыгивайте снежки и трижды прыгните на его сияющую корону, когда он присядет. Затем идите к праздничным воротам справа.

В каждом мире есть движущиеся вафельные платформы, две контрольные точки и секретная звезда над верхней тропинкой. Кот и Оливия анимируются вместе: ожидание, бег, прыжок, приземление, получение урона, радость и победа. При прыжке на существ они превращаются в конфетти.

За мороженое начисляется 100 очков, за существо — 150, за секрет — 500. За завершение мира выдаётся одна звезда, за 60% мороженого — вторая, за секрет — третья. Флажок восстанавливает одно сердечко и сохраняет точку возврата внутри текущего прохождения.

**Аксессуары** открываются автоматически за 25, 65 и 120 разных мороженых. Они меняют только шарф или добавляют корону: лицо, волосы, тёмный костюм и кот остаются прежними.

## Сохранения и звук

- `localStorage`, ключ `olivia-adventure-v1`: открытые миры, лучшие результаты, звёзды, уникальные мороженые, аксессуар и настройка звука.
- Собранное мороженое сохраняется сразу. Повторный сбор даёт очки, но не увеличивает коллекцию второй раз.
- Состояние незавершённого уровня, сердца и флажки не сохраняются между закрытиями страницы. После перезагрузки уровень начинается заново.
- Сохранения относятся к браузеру и адресу сайта; они не синхронизируются между телефоном и компьютером. Переход с `file://` на GitHub Pages создаст отдельное сохранение. В приватном режиме или при блокировке хранилища прогресс может храниться только в открытой вкладке; игра сообщает об этом.
- Музыка и эффекты созданы синтезатором Web Audio; начинают звучать после действия игрока. Кнопка динамика отключает звук.

## Разработка и проверка

```sh
node --test tests/*.test.cjs
```

Тесты проверяют физику прыжков, coyote time, буфер, тонкие платформы, перенос движущейся платформой, достижимость всех обязательных разрывов пяти уровней и повреждённые сохранения.

Дополнительная проверка в настоящем Chromium (Playwright нужен только разработчику):

```sh
npm install --no-save playwright
npx playwright install chromium
node server.cjs
# В другом терминале:
node tests/browser-smoke.cjs
node tests/browser-playthrough.cjs
```

При отсутствии браузера Playwright можно указать переменную `BROWSER_PATH` с путём к локальному Chrome. Снимки сохраняются в `test-results/`, которая не входит в Git. Проверяются клавиатура, прыжок, пауза, повтор, меню, сохранение настройки, мобильные кнопки, горизонтальный экран, относительные ресурсы из подпапки и запуск через `file://`.

## Файлы

```text
index.html                  интерфейс и подключение ресурсов
styles.css                  адаптивная вёрстка и сенсорные кнопки
js/core.js                  физика и безопасное чтение сохранений
js/levels.js                пять миров, препятствия и маршруты
js/art.js                   оригинальная пиксельная графика Canvas
js/audio.js                 оригинальная генеративная музыка и эффекты
js/game.js                  игровой цикл, существа, босс, меню
assets/favicon.svg          оригинальный значок мороженого
tests/                      проверки
server.cjs                  необязательный локальный сервер
.github/workflows/pages.yml автоматическая публикация
.nojekyll                   отключение обработки Jekyll
```

Внешний референс Оливии не был приложен к исходному запросу. Текущие внешность и одежда нарисованы по текстовому описанию; портретное сходство с конкретным фото не заявляется. Все персонажи, рисунки, музыка и эффекты созданы для этой игры, материалы сторонних игр не использованы.
